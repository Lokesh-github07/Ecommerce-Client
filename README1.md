# Ecommerce-Client
# 🛒 ShopEase

A full-stack e-commerce platform built with **React, Node.js, Express.js, MongoDB, and REST APIs**.

## 🚀 Features
- 🔐 User Registration & Login
- 🛍️ Product Browsing & Search
- 📦 Product Details
- 🛒 Shopping Cart
- ❤️ Wishlist
- 💳 Checkout & Payments
- 📋 Order Management
- 👤 User Profile
- 👨‍💼 Admin Dashboard
- 📊 Product & Order Management
- 📱 Responsive Design

## 🛠️ Tech Stack
**Frontend**
- React.js
- Vite
- React Router
- Axios
- CSS

**Backend**
- Node.js
- Express.js
- REST APIs
- JWT Authentication
- bcrypt

**Database**
- MongoDB
- Mongoose

⚙️ Installation
Frontend
cd client
npm install
npm run dev
Backend
cd server
npm install
npm run dev

🔐 Environment Variables
Create a .env file in the server directory:

PORT=5000
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
CLIENT_URL=http://localhost:5173
